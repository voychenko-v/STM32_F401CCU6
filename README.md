# STM32 I2C Clock: SSD1306 + DS1307

Годинник на STM32F401CCU6: час і дата з RTC DS1307 виводяться на OLED-дисплей SSD1306 (128×64) по спільній шині I2C.

![Demo](demo.gif)

## Можливості

- Ініціалізація та робота з дисплеєм SSD1306 128×64
- Зчитування часу й дати з DS1307 однією транзакцією (7 байтів)
- Час у форматі `HH:MM:SS`, дата у форматі `EEE DD.MM.YYYY` (наприклад, `Sat 14.02.2026`)
- Оновлення екрана кілька разів на секунду
- Налагоджувальний вивід через USB CDC (`printf`)

## Залізо

| Компонент | Опис | I2C адреса |
|---|---|---|
| STM32F401CCU6 | Мікроконтролер | n/a |
| SSD1306 | OLED 128×64 | `0x3C` |
| DS1307 | RTC-модуль | `0x68` |

Обидва пристрої підключені до **I2C1** (SDA/SCL) із підтяжкою до живлення. Швидкість шини: 100 кГц.

## Драйвери

Драйвери написані з нуля поверх STM32 HAL (`HAL_I2C_Mem_Write/Read`), без сторонніх бібліотек.

**SSD1306** (`ssd1306.c/.h`)
- Ініціалізація дисплея (charge pump, адресація, remap тощо)
- Фреймбуфер 1024 байти в RAM: усі функції малювання змінюють лише буфер, а `ssd1306_update()` відправляє його на дисплей
- Піксельна графіка: `ssd1306_set_pixel`
- Текст: шрифт 5×7 з масштабуванням (`ssd1306_draw_char`, `ssd1306_draw_string`)

**DS1307** (`main.c`, `ds1307_read`)
- Зчитування регістрів часу й дати
- Перетворення BCD → десяткові значення
- Маскування службових бітів (Clock Halt, режим 24 год)
