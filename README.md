# STM32 Weather Clock: SSD1306 + DS1307 + BME280

Метеостанція-годинник на STM32F401CCU6: час і дата з RTC DS1307, температура, вологість і тиск з BME280 виводяться на OLED SSD1306 (128×64). Значення дублюються в термінал через USB CDC.

![Demo](demo.gif)

## Можливості

- Час `HH:MM:SS` і дата `EEE DD.MM.YYYY`
- Температура (°C), вологість (%RH), тиск (hPa)
- Оновлення даних раз на секунду через `HAL_GetTick()`, без `HAL_Delay()`
- Дублювання всіх значень у `printf` (USB CDC)

## Залізо

| Компонент | Інтерфейс | Примітка |
|---|---|---|
| STM32F401CCU6 | n/a | MCU |
| SSD1306 128×64 | I2C1 | адреса `0x3C` |
| DS1307 | I2C1 | адреса `0x68` |
| BME280 | SPI1 | CS: софтверний GPIO, mode 0 |

## Підключення

### I2C1 (SSD1306 + DS1307, спільна шина)

| Сигнал | STM32 | SSD1306 | DS1307 |
|---|---|---|---|
| SCL | PB6 | SCL | SCL |
| SDA | PB7 | SDA | SDA |
| VCC | n/a | 3.3 В | 3.3 В |
| GND | GND | GND | GND |

### SPI1 (BME280)

| Сигнал | STM32 | BME280 |
|---|---|---|
| SCK | PA5 | SCL |
| MOSI | PA7 | SDA |
| MISO | PA6 | SDO |
| CS | PA4 (GPIO, `BME_CS`) | CSB |
| VCC | n/a | 3.3 В |
| GND | GND | GND |

## Драйвери

Усі драйвери написані з нуля поверх STM32 HAL, без сторонніх бібліотек.

- **SSD1306** (`ssd1306.c/.h`): ініціалізація, фреймбуфер 1024 байти, піксель, текст зі шрифтом 5×7 і масштабуванням
- **DS1307** (`main.c`): зчитування 7 регістрів однією транзакцією, BCD → DEC
- **BME280** (`bme280.c/.h`): SPI-транспорт, зчитування калібрування, цілочисельна компенсація T/P/H за datasheet Bosch
