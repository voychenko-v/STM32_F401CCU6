
# Світлофор на STM32 (Traffic Light Controller)
 
![demo](demo.gif)
 
### Стандартна послідовність перемикання
 
| Стан | Опис |
|---|---|
| **Зелений** | Дозволяє рух |
| **Зелений миготливий** | Попереджає, що час дії дозволеного сигналу закінчується і скоро буде ввімкнено заборонний сигнал |
| **Жовтий** | Забороняє рух і попереджає про майбутню зміну сигналів |
| **Червоний** | Забороняє рух |
| **Червоний + жовтий** | Попереджають про наступне ввімкнення зеленого сигналу (рух все ще заборонено) |
| **Зелений** | Цикл повторюється |
 
### Особливий режим
 
| Стан | Опис |
|---|---|
| **Жовтий миготливий** | Дозволяє рух і інформує про наявність нерегульованого перехрестя або пішохідного переходу |
 
Режим вмикається та вимикається натисканням кнопки — перемикає світлофор
між звичайним циклом і аварійним миготінням жовтого.
 
## Реалізація
 
Перемикання станів реалізоване **не через опитування (polling) часу в основному
циклі**, а через **апаратний таймер (TIM) в режимі переривань**:
 
- При вході в кожен стан для таймера встановлюється новий період (`ARR`),
  що відповідає тривалості цього стану (або інтервалу миготіння).
- Таймер запускається, і мікроконтролер більше не витрачає ресурси на перевірку
  часу в `while(1)` — перехід у наступний стан відбувається виключно
  в обробнику переривання `HAL_TIM_PeriodElapsedCallback()`.
- Для станів миготіння (`GREEN_BLINK`, `YELLOW_BLINK`) таймер налаштовується
  на короткий інтервал (`BLINK_INTERVAL`), і кожне переривання перемикає стан
  світлодіода, поки не вичерпається лічильник миготінь (або поки не натиснуть кнопку).
Такий підхід дозволяє основному циклу `main()` лишатися вільним і не блокує
процесор постійними перевірками `HAL_GetTick()`.
 
### Обробка кнопки
 
Натискання кнопки обробляється через зовнішнє переривання (EXTI) з дебаунсом
(програмним придушенням дребезгу контактів за часом). У обробнику переривання
кнопки викликається функція, яка перемикає світлофор між звичайним циклом
та аварійним режимом жовтого миготіння.
