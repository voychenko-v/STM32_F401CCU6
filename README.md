# STM32 Safe Lock — електронний кодовий замок на енкодері

Навчальний проєкт: реалізація "сейфа" на STM32 (Black Pill, STM32F401/F411) з уведенням
пін-коду через поворотний квадратурний енкодер, за аналогією з механічними кодовими замками.

## Апаратна частина

- **MCU:** STM32F4 (Black Pill)
- **Енкодер:** квадратурний, канали A/B підключені до TIM1 (Encoder Mode, режим TI12 / X4)
- **Вивід логів:** USB CDC (Virtual COM Port), без додаткового UART-перехідника

## Принцип роботи

Обертання вала емулює логіку механічного сейфового лімба:

1. Обертання в один бік **інкрементує поточну цифру** коду (0 → 9 → 0, циклічно).
2. **Зміна напрямку обертання** фіксує поточну цифру як введену і починає набір наступної.
3. Після введення заданої кількості цифр код перевіряється автоматично.
4. Правильний код → розблокування. Неправильний → лічильник спроб +1.
5. Вичерпано всі спроби → у лог виводиться повідомлення про блокування, енкодер і кнопка вимикаються.
   Для нових спроб потрібне **перезавантаження МК** (скидання живленням або кнопкою RESET).

Декодування сигналу A/B відбувається апаратно через **Encoder Mode таймера TIM1** (X4:
рахуються фронти обох каналів), без навантаження CPU переривань на кожен фронт.
 
Натискання кнопки **скидає набраний код і починає нову спробу**:
 
- скидається лічильник підтверджених цифр і напрямок обертання;
- позиція диска (`ring_index`) **не змінюється**, як у механічному сейфі: диск лишається там, де є;
- лічильник невдалих спроб **не змінюється** — скидання набору не витрачає спробу;
- після розблокування або вичерпання спроб кнопка ігнорується.

## Поточний стан реалізації

- [x] Апаратне X4-декодування квадратурного сигналу через `TIM1 Encoder Mode`
- [x] Накопичення "сирих" імпульсів лічильника без втрати залишку (`accumulated_remainder`)
- [x] Циклічний індекс цифри 0–9 (`ring_index`)
- [x] Фіксація цифри по зміні напрямку обертання
- [x] Перевірка коду з фіксованою довжиною (3 цифри, задається в `combination[]`)
- [x] Ліміт спроб (3) з виводом введеного коду та кількості спроб, що залишилися
- [x] Блокування після вичерпання спроб (без автоматичного перезавантаження), вихід з основного циклу
- [x] Кнопка енкодера (EXTI4) для скидання набраного коду, з антибрязкотом
- [x] Логування процесу набору через USB CDC (`printf`)

### Правильний код (3 7 2)
 
```
Safe lock ready. Enter 3 digits.
Dial: 1 (dir set: CW)
Dial: 2
Dial: 3
Dial: 2 Digit 1 confirmed: 3
Dial: 1
---
Dial: 8 Digit 2 confirmed: 7
Dial: 9
---
Dial: 1 Digit 3 confirmed: 2
SAFE UNLOCKED!
```
 
### Неправильний код (спроба 1 з 3)
 
```
Dial: 1 (dir set: CW)
Dial: 2
---
Dial: 3 Digit 1 confirmed: 4
Dial: 2
---
Dial: 0 Digit 2 confirmed: 9
Dial: 1
---
Dial: 2 Digit 3 confirmed: 3
Wrong code: 4 9 3. Attempts left: 2
```
