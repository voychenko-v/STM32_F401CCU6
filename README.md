# STM32F411 Black Pill: Blink + кнопка (регістри)
 
Світлодіод мигає з рівними проміжками часу, кнопка змінює період мигання.
Логіка (мигання, кнопка, таймінг) реалізована через прямий доступ до регістрів, без HAL.
 
## Пристрій і піни
 
- Плата: Black Pill (STM32F411CEU6), HCLK 84 МГц
- Світлодіод: **PC13** (активний низьким рівнем)
- Кнопка: **PA0** (pull-up, натиснута = 0)
 
## Як працює
 
- **TIM2** вільно рахує мілісекунди (`TIM2->CNT`), без `HAL_Delay`.
- Світлодіод перемикається через `GPIOC->ODR`, кнопка читається через `GPIOA->IDR` з антидребезгом 30 мс.
- Кожне натискання перемикає період: 100 / 250 / 500 / 1000 / 2000 мс.
